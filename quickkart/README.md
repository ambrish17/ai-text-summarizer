# QuickKart

QuickKart — e-commerce scaffold (Django + DRF backend, Next.js frontend, Docker Compose).

This initial commit provides a minimal scaffold to get started. It includes:
- Docker Compose with Postgres and Redis
- Django backend with a small `store` app and REST framework
- Next.js frontend skeleton with Tailwind-ready CSS

To run locally (after creating .env and updating values):

1. docker compose up --build

2. Backend available at http://localhost:8000
3. Frontend available at http://localhost:3000

See README for next steps.
